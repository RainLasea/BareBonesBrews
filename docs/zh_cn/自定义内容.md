# 自定义内容

配方在运行时从原版酿造表生成。装新的药水 mod 之后重启即可，不需要写配置。

需要自己写内容的有三种情况：

| 目的 | 页面 |
|---|---|
| 换材料、改煮制时间、加新配方 | [自定义配方](自定义配方) |
| 用脚本写配方和标签 | [KubeJS](KubeJS) |
| 换贴图、改物品名 | [资源包](资源包) |

## 配方 ID

```
barebonesbrews:rough_brewing/<形态>/<药水的命名空间>/<药水路径>
```

形态为 `potion`、`splash`、`lingering`。

```
barebonesbrews:rough_brewing/potion/minecraft/strength
barebonesbrews:rough_brewing/splash/minecraft/strength
barebonesbrews:rough_brewing/lingering/minecraft/strength
barebonesbrews:rough_brewing/potion/minecraft/long_night_vision
```

可饮、喷溅、滞留三份配方各用各的 ID。

"粗制的药水"的 ID 是 `barebonesbrews:rough_minecraft_awkward_from_cauldron`，没有形态这一段。

装了 Hexalia 时前缀改为 `hexalia_rough/`，材料中不含蘑菇。

## 物品组件

```json
"components": {
  "barebonesbrews:source_potion": "minecraft:strength",
  "minecraft:potion_contents": {
    "custom_effects": [{ "id": "minecraft:strength", "amplifier": 0, "duration": 1800 }]
  }
}
```

`barebonesbrews:source_potion` 写原药水 ID，`minecraft:potion_contents` 写效果。物品名和提示都读这两个组件。

## 导出生成的配方

配置中打开：

```toml
dump_generated_recipes = true
```

重启后生成的配方写入 `config/barebonesbrews/generated/`。也可以直接改 `examples/datapack` 里的 `strength.json`。

## 生效方式

配方用 `/reload` 生效。配置项需要重启。
