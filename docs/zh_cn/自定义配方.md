# 自定义配方

配方类型为 `barebonesbrews:rough_brewing`，放在 `data/<命名空间>/recipe/<路径>.json`。

## 字段

```json
{
  "type": "barebonesbrews:rough_brewing",
  "ingredients": [
    { "tag": "c:mushrooms" },
    { "item": "minecraft:blaze_powder" }
  ],
  "result": {
    "id": "barebonesbrews:rough_potion",
    "count": 1,
    "components": {
      "barebonesbrews:source_potion": "minecraft:strength",
      "minecraft:potion_contents": {
        "custom_effects": [{ "id": "minecraft:strength", "amplifier": 0, "duration": 1800 }]
      }
    }
  },
  "duration": 300
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `ingredients` | 是 | 1 到 5 个材料，顺序不限 |
| `result` | 是 | 物品栈，可带组件 |
| `duration` | 否 | 煮制刻数，默认 400。20 刻 = 1 秒 |
| `experience` | 否 | 完成后给予的熟练度，默认 0 |

## ingredients

```json
{ "item": "minecraft:sugar" }
{ "tag": "c:mushrooms" }
```

`c:mushrooms` 是通用标签，会自动包含其他 mod 添加的蘑菇。

## result 组件

`barebonesbrews:source_potion` 写原药水 ID。缺这个组件时物品名会显示为通用的"粗制药水"。

`minecraft:potion_contents` 的 `custom_effects` 每项接受：

| 字段 | 默认 |
|---|---|
| `id` | 必填 |
| `amplifier` | 0 |
| `duration` | 0 |
| `ambient` | false |
| `show_particles` | true |
| `show_icon` | 同 `show_particles` |

颜色由 `custom_effects` 计算，不需要写 `custom_color`。

## 覆盖默认配方

文件名对应配方 ID。例如覆盖力量药水：

`data/my_pack/recipe/rough_brewing/potion/minecraft/strength.json`

```json
{
  "type": "barebonesbrews:rough_brewing",
  "ingredients": [
    { "tag": "c:mushrooms" },
    { "item": "minecraft:amethyst_shard" }
  ],
  "result": {
    "id": "barebonesbrews:rough_potion",
    "count": 1,
    "components": {
      "barebonesbrews:source_potion": "minecraft:strength",
      "minecraft:potion_contents": {
        "custom_effects": [{ "id": "minecraft:strength", "amplifier": 0, "duration": 1800 }]
      }
    }
  },
  "duration": 200
}
```

一个药水的可饮、喷溅、滞留是三条独立配方，要分别覆盖。

## 添加新配方

`data/my_pack/recipe/hearty_brew.json`

```json
{
  "type": "barebonesbrews:rough_brewing",
  "ingredients": [
    { "tag": "c:mushrooms" },
    { "item": "minecraft:golden_apple" },
    { "item": "minecraft:glistering_melon_slice" }
  ],
  "result": {
    "id": "minecraft:potion",
    "count": 1,
    "components": {
      "minecraft:potion_contents": {
        "custom_effects": [
          { "id": "minecraft:regeneration", "amplifier": 1, "duration": 900 },
          { "id": "minecraft:absorption", "amplifier": 0, "duration": 2400 }
        ]
      }
    }
  },
  "duration": 600
}
```

产出原版药水瓶时不需要 `source_potion`。

## 材料匹配

同一组材料只匹配一条配方。材料组合重复的配方不会生效。

mod 生成配方时会跳过材料重复的药水（例如发酵蛛眼对应迟缓、伤害、隐身三种），这些药水没有默认配方。

## 热源

默认值：

```toml
cauldron_heat_sources = ["#barebonesbrews:heat_sources"]
```

三种写法，可以混用：

```toml
cauldron_heat_sources = [
  "minecraft:magma_block",
  "#minecraft:campfires",
  "minecraft:furnace[lit=true]",
]
```

带 `lit` 属性的方块必须点着才算热源，`[lit=false]` 可以反转。

写错方块 ID、属性名或属性值的那一条不会匹配任何方块，也不会报错。

改这个配置项之后，`barebonesbrews:heat_sources` 标签不再被读取。

此项对 Hexalia 无效。

标签写法：

`data/my_pack/tags/block/heat_sources.json`

```json
{
  "replace": false,
  "values": ["minecraft:diamond_block", "#minecraft:campfires"]
}
```

标签在匹配时实时读取，`/reload` 后生效。
