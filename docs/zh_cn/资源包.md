
## 名称

带 `.named` 的键用于显示了原药水名的物品：

```json
"item.barebonesbrews.rough_potion.named": "Crude %s",
"item.barebonesbrews.rough_splash_potion.named": "Crude Splash %s",
"item.barebonesbrews.rough_lingering_potion.named": "Crude Lingering %s"
```

`%s` 替换为原药水名。中文不留空格，英文保留。

不带 `.named` 的键在没有 `source_potion` 组件时使用：

```json
"item.barebonesbrews.rough_potion": "Crude Potion"
```

自定义语言文件放在 `assets/<命名空间>/lang/<语言>.json`，只需写要改的键。

示例：

```json
{
  "item.barebonesbrews.rough_potion.named": "土法%s",
  "item.barebonesbrews.rough_splash_potion.named": "土法喷溅%s",
  "item.barebonesbrews.rough_lingering_potion.named": "土法滞留%s",
  "item.barebonesbrews.rough_potion": "土法药水"
}
```

## 流体

```json
"fluid_type.barebonesbrews.rough_potion": "Crude Potion"
```

该流体没有对应的桶物品，此键在流体信息被其他 mod 显示时使用。
